# 学业预警知识问答系统

基于LangChain和RAG（检索增强生成）技术构建的智能问答系统，专注于回答学生关于《软件与人工智能学院本科生学业预警实施办法》的问题。

## 📋 项目概述

本系统以《广州软件学院软件与人工智能学院本科生学业预警实施办法》PDF文档为唯一知识来源，通过RAG技术实现精准的学业预警问题回答。

## 🛠️ 技术栈

| 组件 | 技术选型 |
|------|----------|
| 文档加载 | PyPDFLoader |
| 文本分割 | RecursiveCharacterTextSplitter |
| Embedding模型 | nomic-embed-text (Ollama) |
| 向量数据库 | Chroma |
| BM25检索 | rank_bm25 |
| 混合检索 | EnsembleRetriever (权重0.5/0.5) |
| 重排序模型 | BAAI/bge-reranker-base |
| LLM | qwen3:0.6b (Ollama) |
| Web框架 | Flask |

## 📁 项目结构

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 确保Ollama服务运行

```bash
# 启动Ollama服务
ollama serve

# 确认模型已下载
ollama list
# 应包含：nomic-embed-text, qwen3:0.6b
```

### 3. 运行系统

```bash
# Web服务模式
python app.py

# 或命令行测试模式
python app.py --test
```

### 4. 访问系统

打开浏览器访问：http://127.0.0.1:5000

## 💬 示例问题

系统可以回答以下类型的问题：

| 序号 | 问题 |
|------|------|
| 1 | 学业预警工作由谁负责？ |
| 2 | 什么情况下会被黄色预警？ |
| 3 | 红色预警的条件是什么？绩点低于多少算红色预警？ |
| 4 | 绩点1.7，2门必修不及格会收到什么预警？ |
| 5 | 如果一学期挂了4门必修课，会收到什么预警？会有哪些措施？ |
| 6 | 我有3门选修课没过，会预警吗？ |

## 🔧 系统架构

```
用户问题
    ↓
┌─────────────────┐
│  混合检索器      │  ← 向量检索(50%) + BM25(50%)
└─────────────────┘
    ↓
┌─────────────────┐
│ Cross-Encoder   │  ← 重排序，选取Top4
│   重排序模型     │
└─────────────────┘
    ↓
┌─────────────────┐
│  LLM (qwen3)   │  ← 基于排序结果生成回答
└─────────────────┘
    ↓
回答
```

## ⚠️ 注意事项

1. 首次运行会自动初始化RAG系统（包括加载PDF、构建向量库），可能需要等待数秒
2. 确保Ollama服务正在运行，否则系统无法正常工作
3. 系统仅能回答与学业预警相关的问题

## 📝 核心代码说明

详见 `app.py` 中的注释，主要包含：

- `init_rag_system()`: 初始化RAG系统组件
- `rerank_docs()`: 对检索结果进行重排序
- `answer_question()`: 回答用户问题的主函数
